# Katana Bot

Telegram-бот для модерации групп и комментариев к постам каналов. Работает на Python 3.13, aiogram 3 и SQLite.

## Запуск

1. Создайте бота через [@BotFather](https://t.me/BotFather).
2. Выполните из папки проекта:

   ```bash
   .venv/bin/python -m pip install -r requirements.txt
   cp -n .env.example .env
   ```

3. Впишите токен в `.env` после `BOT_TOKEN=`.
4. Добавьте бота администратором группы с правом «Удаление сообщений». Для комментариев добавьте его в группу обсуждений, привязанную к каналу.
5. Запустите `.venv/bin/python main.py` или откройте `main.py` в PyCharm и нажмите Run.

## Команды

| Команда | Действие |
| --- | --- |
| `/katana` | Показать справку и состояние фильтра |
| `/links on` | Включить удаление ссылок в текущей группе |
| `/links off` | Выключить фильтр ссылок |
| `/del` | Удалить сообщение, на которое отвечает администратор |

Настройки и удаление доступны администраторам. Фильтр по умолчанию выключен и включается для каждой группы отдельно. Он обрабатывает ссылки, распознанные Telegram, в новых и отредактированных сообщениях и подписях к медиа. Ссылки администраторов и автоматические пересылки постов канала сохраняются. В группе обсуждений фильтр применяется и к комментариям, и к остальным сообщениям группы.

Настройки хранятся в `katana.sqlite3` рядом с `main.py`.
