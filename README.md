# Katana Moderator

**Telegram-бот для автоматической модерации групп и комментариев к каналам.** Katana фильтрует мат, спам и флуд, проверяет новичков и помогает администраторам разбирать жалобы и отменять ошибочные действия.

## Возможности

| | |
| --- | --- |
| **Автомодерация** | Фильтр мата с распознаванием масок, сокращений и некоторых опечаток. Фильтры ссылок, антифлуд, повторы и исключения для доменов и участников. |
| **Защита новичков** | Капча с кнопками, антирейд и локальный классификатор спама для первых суток после вступления. |
| **Комментарии к каналам** | Модерация в привязанной группе обсуждений с отдельным режимом для распознанных веток. Автопересланные посты сохраняются. |
| **Наказания и отмена** | Предупреждения, муты, баны, ступенчатые санкции Katana Strike, обжалование и восстановление сохранённых копий сообщений. |
| **Работа администраторов** | Жалобы, журнал действий, статистика, настройки в Telegram и опциональная веб-панель. |
| **Дополнительные инструменты** | Репутация участников, объявления по расписанию и локальный анализ текста и изображений через Ollama. |

Фильтр мата включён по умолчанию. Он проверяет новые и отредактированные сообщения обычных участников, включая подписи к медиа. Остальные правила настраиваются отдельно для каждой группы. Один экземпляр бота может обслуживать несколько групп.

## Быстрый старт

### Docker Desktop

Нужен Docker Desktop или Docker Engine с Compose. Для собственного экземпляра создайте бота через [@BotFather](https://t.me/BotFather) командой `/newbot`.

```bash
git clone https://github.com/livej0urnal/katana-bot.git
cd katana-bot
cp -n .env.example .env
```

1. Впишите токен в `BOT_TOKEN` в файле `.env`.
2. Добавьте бота в группу администратором. Выдайте право **«Удаление сообщений»**. Для капчи, мутов и банов в супергруппе нужно также право **«Блокировка участников»**.
3. Запустите сервис.

   ```bash
   docker compose up -d --build --no-deps bot
   docker compose logs -f bot
   ```

4. Отправьте в группе `/settings` от имени администратора. Ответ покажет, какие права и правила действуют. Для проверки фильтра отправьте новое сообщение от обычного участника.

Для комментариев под постами добавьте бота в **группу обсуждений**, связанную с каналом через **Настройки канала → Обсуждение**. Для одного токена запускайте один процесс polling. Остановите запуск в PyCharm перед запуском контейнера с тем же токеном.

### Без Docker

```bash
python3.13 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python main.py
```

В PyCharm выберите интерпретатор из `.venv` и запустите `main.py`. Конфигурация токена и права группы те же.

## Команды

### Настройка защиты

| Команда администратора | Действие |
| --- | --- |
| `/settings` | Показать правила группы и права бота. Антифлуд и Shadow Mode можно переключить кнопками. |
| `/profanity delete` · `/profanity log` · `/profanity off` | Удалять мат, записывать срабатывания или выключить фильтр. |
| `/links on` · `/links off` | Включить или выключить фильтр ссылок. |
| `/allow add domain example.com` | Разрешить домен и его поддомены. |
| `/allow add user ID` | Исключить участника из автоматической модерации и капчи. Используйте `/allow remove`, чтобы удалить исключение. |
| `/protect flood on` | Удалять сообщение при 6 сообщениях или 3 повторах за 10 секунд от одного автора. |
| `/protect gate on` | Просить новичка решить пример кнопкой. После успешной проверки бот снимает ограничение и удаляет своё приглашение пройти капчу. Если проверка осталась непройденной, временное ограничение истекает через 10 минут. |
| `/protect raid on` | Включать проверку новичков на 5 минут при 6 вступлениях или 6 удалениях за спам за минуту. |
| `/protect comments strict` · `inherit` · `off` | В распознанных комментариях блокировать ссылки, применять правила группы или отключить автомодерацию. |
| `/protect newspam log` · `delete` · `off` | Настроить классификатор спама для новичков. |
| `/protect shadow on` | Убрать публичные уведомления об автоматических санкциях. События остаются в журнале. |

Для переключателей `flood`, `gate`, `raid` и `shadow` используется соответствующая команда с `off`.

### Действия и отмена

| Команда | Действие |
| --- | --- |
| `/del` | Удалить сообщение ответом на него. |
| `/cleanup 30m` | Сразу удалить до 30 сообщений, отмеченных в режиме `/profanity log` за последние 30 минут. |
| `/restore ID` | Опубликовать сохранённую копию удалённого сообщения от имени Katana. |
| `/warn [причина]` · `/mute МИНУТЫ` · `/tempban МИНУТЫ` · `/ban` | Предупредить, ограничить или забанить участника ответом на его сообщение. |
| `/unmute ID` · `/unban ID` | Снять мут или разрешить участнику заново вступить. |
| `/autoban on` · `/autoban off` | Управлять баном после трёх словарных удалений за мат от одного участника за 24 часа. |
| `/protect strike on` · `/protect strike off` | Управлять баллами за предупреждения и автоматические удаления. 3 балла дают мут на час, 5 — на сутки, 10 — бан. Баллы истекают через 24 часа. |
| `/reports` · `/audit` · `/stats` | Получить жалобы, журнал или статистику в личном чате. Сначала нажмите **Start** в личке бота. |
| `/announce МИНУТЫ ТЕКСТ` · `/announce off` | Установить или выключить периодическое объявление группы. |

При включённом Katana Strike для автоматических удалений применяется его шкала. Команды в этой таблице доступны администраторам.

**Восстановление.** Поддерживаемое содержимое сохраняется до семи дней. ID указан в отчёте об очистке, ответе на `/del` или журнале. Восстановленная копия получает новое время, отправителя и ID. `/cleanup` ограничен известными боту сообщениями младше 48 часов. Бот пропускает автопересланные посты и закреплённое сообщение, которое Telegram возвращает в информации о группе.

### Для участников

| Команда | Действие |
| --- | --- |
| `/start` · `/help` · `/katana` | Открыть справку. |
| `/report` | Пожаловаться на сообщение или комментарий ответом на него. |
| `/thanks` · `/rep` | Поблагодарить автора полезного сообщения или проверить репутацию. |
| `/appeal ID_ГРУППЫ НОМЕР_ДЕЙСТВИЯ ПРИЧИНА` | Обжаловать свою санкцию в личном чате с ботом. |

Жалоба сама по себе не удаляет сообщение. Бот хранит идентификаторы и фрагмент текста до 120 символов и учитывает одну жалобу от участника на сообщение.

## Дополнительные сервисы

### Ollama и ML-антиспам

Локальный классификатор новичков обучен на небольшом синтетическом наборе. Для проверки на сообщениях вашей группы начните с `/protect newspam log`.

Модель Ollama дополняет локальные фильтры. Укажите `OLLAMA_TEXT_MODEL` и при необходимости `OLLAMA_VISION_MODEL` в `.env`. При запуске на хосте настройте `OLLAMA_URL`. Контейнер использует сервис `ollama` или заданный `KATANA_DOCKER_OLLAMA_URL`.

```bash
docker compose --profile ai up -d --wait ollama
docker compose --profile ai exec ollama ollama pull gemma3:4b
```

- `/protect ai log` проверяет текст на спам, мошенничество, рекламу, токсичность, оскорбления и замаскированный мат. Модель получает до четырёх предыдущих реплик в группе или ветке. Метка мата от модели не засчитывается в словарный автобан.
- `/protect nsfw log` проверяет доступные боту фотографии в чате. Для этого нужна модель с поддержкой изображений.
- `/protect profile log` проверяет последнее доступное фото профиля при вступлении. В режиме `delete` бот может удалить до пяти недавних сообщений участника, которые видел за последние 10 минут.

Для каждого из этих режимов доступны `log`, `delete` и `off`. При включённом анализе данные передаются на настроенный адрес Ollama. Если модель недоступна, локальные фильтры продолжают работать.

### SQLite, PostgreSQL и Redis

SQLite используется по умолчанию. При запуске в Docker база хранится в томе `bot_data`, при локальном запуске — в `katana.sqlite3` или по пути `SQLITE_PATH`.

<details>
<summary>PostgreSQL и перенос существующей базы</summary>

Задайте `POSTGRES_PASSWORD` в `.env`. Для запуска на хосте добавьте `DATABASE_URL=postgresql+psycopg://katana:ПАРОЛЬ@127.0.0.1:5433/katana`. Для бота в контейнере вместо этого задайте `KATANA_DOCKER_DATABASE_URL` с адресом `postgres:5432`. Спецсимволы пароля в URL нужно кодировать.

```bash
docker compose up -d --wait postgres
.venv/bin/python -m alembic upgrade head
```

Если бот запускается в контейнере, примените миграции через `docker compose run --build --rm --no-deps bot python -m alembic upgrade head`.

Для перехода с SQLite остановите бота. С хоста укажите `DATABASE_URL` и запустите `.venv/bin/python import_sqlite.py katana.sqlite3` после применения миграций к пустой базе. Импорт оставляет исходный файл на месте и выводит количество строк по таблицам. После переключения проверьте `/settings` и `/reports`. При возврате к SQLite новые данные из PostgreSQL придётся перенести отдельно.

</details>

<details>
<summary>Копирование SQLite в том нового контейнера</summary>

Остановите бот и выполните до первого запуска контейнера с SQLite. Команда записи завершится ошибкой, если база в томе уже существует.

```bash
snapshot_dir=$(mktemp -d)
sqlite3 katana.sqlite3 ".backup '$snapshot_dir/katana.sqlite3'"
docker compose run --build --rm -T --no-deps bot python -c '
import sys
from pathlib import Path

snapshot = sys.stdin.buffer.read()
if not snapshot.startswith(b"SQLite format 3\x00"):
    raise SystemExit("Invalid SQLite snapshot")
with Path("/data/katana.sqlite3").open("xb") as target:
    target.write(snapshot)
' < "$snapshot_dir/katana.sqlite3"
```

</details>

Короткие окна антифлуда и антирейда хранятся в памяти по умолчанию. Для Redis запустите `docker compose --profile cache up -d redis`. Для контейнера укажите `KATANA_DOCKER_REDIS_URL=redis://redis:6379/0`. Для запуска на хосте установите `requirements-redis.txt` и задайте `REDIS_URL=redis://127.0.0.1:6380/0`.

### Веб-панель

```bash
.venv/bin/python -m pip install -r requirements-dashboard.txt
.venv/bin/python -m uvicorn dashboard:app --host 127.0.0.1 --port 8000
```

Владелец установки задаёт `DASHBOARD_PASSWORD` и входит как `admin` на [локальной странице](http://127.0.0.1:8000/). Панель показывает зарегистрированные группы, статус бота и статистику действий.

Для входа администратора отдельной группы задайте одинаковый случайный `DASHBOARD_SESSION_SECRET` для панели и бота. Нажмите **Start** в личке бота, отправьте в группе `/panel` и введите полученный код на [странице входа](http://127.0.0.1:8000/login). Код действует 5 минут, сессия — 30 минут. Доступ ограничен выбранной группой. В веб-панели можно переключать антифлуд и Shadow Mode. Для доступа по сети используйте HTTPS.

## Разработка

Python 3.13 · aiogram 3 · SQLite или PostgreSQL · SQLAlchemy и Alembic · опционально Redis, FastAPI и Ollama.

| Файлы | Назначение |
| --- | --- |
| [main.py](main.py), [handlers.py](handlers.py) | Запуск, обработка сообщений, команды Telegram и планировщик. |
| [moderation.py](moderation.py), [gatekeeper.py](gatekeeper.py) | Правила фильтрации, проверка новичков и антирейд. |
| [storage.py](storage.py), [feature_storage.py](feature_storage.py), [recovery.py](recovery.py) | Настройки, аудит и сохранённые копии удалённых сообщений. |
| [ai_moderation.py](ai_moderation.py), [spam_model.py](spam_model.py) | Анализ через Ollama и локальный классификатор спама. |
| [dashboard.py](dashboard.py), [tests/](tests/) | Веб-панель и автоматические тесты. |

```bash
.venv/bin/python -m unittest discover -s tests -v
```

[GitHub Actions](.github/workflows/ci.yml) проверяет бота и дополнительные сервисы без токена Telegram. Для интеграционного прогона на Mac используйте `./scripts/test-local.sh`. Параметр `--with-ollama` добавляет проверку модели на тестовом тексте и изображении.

Локальный `compose.override.yaml` перезапускает процесс бота после сохранения Python-файлов. Изменения зависимостей или Dockerfile требуют `docker compose up -d --build --no-deps bot`, изменения `.env` — `docker compose up -d --force-recreate --no-deps bot`. Для запуска только с кодом из образа используйте `docker compose -f compose.yaml up -d --build --no-deps bot`.
